# Premium Tech 🛍️

A multi-page e-commerce website for **Premium Tech** — a brand selling premium-quality tech accessories (mice, mobile covers, cables, earphones, chargers, ring lights, mobile stands, and smartwatches) sourced directly from Lahore's Hall Road and Azam Market.

Built as a portfolio project to demonstrate front-end development skills, with the long-term goal of evolving into a real e-commerce business.

## ✨ Features

- Clean, minimal design inspired by Apple's product pages
- Fully responsive layout (mobile, tablet, desktop)
- 8 connected pages with consistent navigation:
  - **Home** — hero section, featured categories, best-selling products, brand values
  - **Shop** — full product grid with category filters and sorting (UI only)
  - **Categories** — browse all product categories
  - **Product Detail** — single product view with image gallery, variants, and related products
  - **About** — brand story and sourcing process
  - **Contact** — contact form and business details
  - **Cart** — shopping cart with order summary
  - **Login** — login / sign-up form
- Custom logo and consistent violet brand identity (`#6d28d9`)
- Smooth entrance animations on the homepage hero section

## 🛠️ Built With

- **HTML5**
- **CSS3** (Flexbox, Grid, custom animations)
- No frameworks yet — built from scratch to strengthen core fundamentals before moving to JavaScript and React
